# Life Companion — MVP Implementation Plan

**Status:** Approved 2026-05-13 by operator.
**Scope:** 7-phase MVP, ~7-8 weeks of work.
**Inherits:** Global rules at `D:\test 2\CLAUDE.md`. Project context at `..\CLAUDE.md`. Guardrails at `.\GUARDRAILS.md`.

---

## 1. Vision

A daily-use mobile + backend product helping everyday people with three pillars:

1. **Life** — reflection, weekly balance review, pattern surfacing
2. **Mind** — Socratic conversation, CBT reframes (NOT therapy)
3. **Health** — medical document translation, visit prep, triage, meds (NOT diagnosis)

**Positioning:** "The friend who knows your feelings, your life patterns, and your health — and never forgets."

**Primary launch:** Russia/CIS. Architecture EU-compliant for later expansion.

---

## 2. North Star metric

| Rank | Metric | Why |
|---|---|---|
| 1 | 30-day retention | Fast signal, weekly cohort tracking |
| 2 | Monthly "this helped me" yes-rate | Direct value signal (target ≥60%) |
| 3 | Voluntary referrals per user | Cleanest proxy for real value |

**Explicitly NOT optimized:** DAU, session length, streak-break rate. These are tracked for billing only — never on the optimization dashboard.

---

## 3. Subscription model

| Tier | Price | Includes |
|---|---|---|
| Free | $0 | Daily check-in, weekly review, 30-day history, 5 AI reflections/week |
| Plus | $3/mo | Unlimited reflections, full history pattern analysis, all three pillars, document interpreter |
| Premium | $8/mo | Plus + 1 monthly 20-min human coach session via affiliate (BetterHelp / RU equivalent) |
| À la carte | $1.99–$4.99 | One-time problem packs: Sleep Reset, Reconnect with Teenager, Beat Sunday Slump, etc. |

**Payments:** Stripe for global + YooKassa for RU.

## 4. Phase plan

| Phase | Scope | Time | Exit criteria |
|---|---|---|---|
| **0 — Bootstrap** | Project scaffold, CLAUDE.md, plan + guardrails persisted, .claude/settings.json, .gitignore, first commit | 0.5d | Bootstrap committed; CI workflow placeholder added |
| **1 — Foundation** | FastAPI app, PostgreSQL schema (users, journal_entries, reflections, patterns, health_docs, subscriptions), Firebase Auth verification middleware, multi-provider LLM adapter, Flutter app skeleton (theme, router, auth screen), Alembic migrations, CI tests | 4d | Server starts; pytest 0 failures; Flutter app builds; reviewer agents pass |
| **2 — Daily check-in + crisis** | Socratic AI reflection (Gemini), crisis detection v1 (regex + LLM classifier + hotline routing), journal CRUD, basic chat UI in Flutter, daily push reminder | 5d | Crisis detection 100% branch coverage; e2e test: user submits "I want to die" → hotline screen shown |
| **3 — Pattern + weekly review** | Embedding-based history analysis, pattern surfacing background job (Celery + Redis), weekly life-balance 6-axis score, radar chart UI | 4d | Pattern surfacing produces ≥1 insight on 4-week history; weekly review screen renders |
| **4 — Health pillar v1** | Medical document upload (PDF/image OCR via PaddleOCR or Tesseract), AI translation to plain language, visit prep flow, doctor letter translation; uses public drug data (OpenFDA, GRLS) | 7d | Upload-blood-test → plain-language summary works; no-diagnosis enforcement test passes |
| **5 — Subscription + payments** | Stripe + YooKassa integration, tier gating middleware, paywall flows, à la carte problem-pack purchase | 5d | Test-mode purchase end-to-end on both providers; tier downgrade preserves data |
| **6 — North Star instrumentation** | Internal metrics dashboard (retention cohorts, "this helped" survey), monthly survey job, referral tracking | 2d | Dashboard shows D1/D7/D30 retention from real users; survey delivered on schedule |
| **7 — Polish + alpha** | Bug fixes from alpha testers, onboarding flow polish, store-listing assets, soft launch with 10 friends | 5d | 10 alpha users active for 7 days, ≥3 say "this helped" |

**Total:** ~32.5 days serial. With agent parallelism (architect + python-reviewer + security-reviewer in parallel on each phase result), realistic 7-8 weeks.

## 6. Agent routing per phase

| Phase | Implementation agent | Review agents (parallel) |
|---|---|---|
| 0 | direct Claude | none (trivial scaffold) |
| 1 | code-architect (plan) → direct Claude (impl) | python-reviewer + security-reviewer + database-reviewer + flutter-reviewer |
| 2 | direct Claude (sensitive area — keep close) | security-reviewer (crisis flow) + python-reviewer + silent-failure-hunter (crisis cannot fail open) |
| 3 | code-architect (analyzer design) → direct Claude | python-reviewer + ml-engineer (embedding pipeline) + performance-optimizer |
| 4 | code-architect → direct Claude | security-reviewer (medical data) + python-reviewer + comment-analyzer (disclaimer copy correctness) |
| 5 | direct Claude | security-reviewer (payment paths) + python-reviewer + pr-test-analyzer |
| 6 | direct Claude | python-reviewer + database-reviewer (cohort queries) |
| 7 | e2e-runner | code-reviewer (general) |

**Aider** invoked for any cross-file refactor >2 files (e.g., adding a new tier requires touching billing/tiers + auth/deps + api/billing simultaneously — Aider preferred).

## 7. Hard guardrails referenced (see core/GUARDRAILS.md for full spec)

1. Crisis detection ships before first user signs up
2. No "you have X" diagnostic language anywhere in the product
3. No streaks-as-shame, no engagement A/B tests on emotional content
4. Disclaimers on every health screen + every emotionally heavy reflection
5. No paywall on crisis support
6. Mental + medical data encrypted at rest with per-user keys
7. 152-ФЗ + GDPR compliance from day 1
